# Extensions to the "timeline" module

Let's add the concept of beats to the timeline module.
It will have subdivisions of 1/4, 1/8 of a beat etc.
The lowest subdivision visible will depend on the zoom level
and should be as small as possible but still be easy to move indicate with the mouse.
When dragging triggers I want them to snap to the smallest visible beat subdivisions.
If I hold down the Option key then snapping will be temporarily disabled.
