Add ability to save patches in a file.
Add "Save Patch..." to the File menu. It will save the front patch or polyPatch and its children to a file.

A patch loaded from or saved to a file will display the file path in the editor window header, after the patch name.
The "Save As..." File menu item will continue to save the entire patch hierarchy.
When a patch hierarchy contains a patch from a file it will only save a reference to the file, unless the patch has been modified.
If modified, it will ask the user if they want to save the modified patch into a file, defaulting to the original path.
Or they can "detach" the patch from the file, which will remove the reference to the file.
Then the patch contents will be saved in the parent JSON data.
Also add a "Detach File" File menu item that will remove the file reference from the front patch if set.
